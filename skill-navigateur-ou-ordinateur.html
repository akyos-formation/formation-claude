Ce skill va-t-il marcher dans le navigateur ?

Le plus simple : demandez-le à Claude (juste en dessous). Ou répondez à 7 questions simples, sans ouvrir le code. L’aiguillage indique si le skill fonctionnera sur claude.ai, dans le navigateur, ou s’il a besoin de l’application Claude installée sur votre ordinateur (Cowork).

La méthode la plus simple : demandez à Claude

  1. Ouvrez une conversation sur claude.ai.
  2. Joignez le skill (fichier .zip ou .skill) avec le trombone. Si Claude n’arrive pas à l’ouvrir, double-cliquez dessus pour le décompresser et joignez le fichier SKILL.md.
  3. Collez le texte ci-dessous et envoyez.
Voici un skill en pièce jointe. Je suis débutant et je ne lis pas le code.
Lis tous ses fichiers (SKILL.md, scripts, fichiers JSON) sans rien exécuter, puis dis-moi :
1. Ce skill doit-il s'utiliser sur claude.ai, dans le navigateur, ou dans l'application Claude installée sur mon ordinateur (Claude Desktop, avec Cowork) ? Réponds par NAVIGATEUR, ORDINATEUR ou LES DEUX.
2. Quelle phrase ou quelle ligne du skill le montre ? Cite-la.
3. Si je peux l'utiliser dans le navigateur avec une adaptation, ce que je dois faire à la place (par exemple joindre un fichier au lieu de donner un dossier).
Explique sans jargon, en 5 lignes maximum.

Les trois verdicts possibles

NavigateurLe skill fonctionne sur claude.ai, depuis n’importe quel ordinateur, sans rien installer.
Navigateur, avec précautionsIl fonctionne sur claude.ai si vous adaptez votre façon de faire, par exemple en joignant les fichiers au lieu d’indiquer un dossier.
OrdinateurIl a besoin de l’application Claude installée sur votre Mac ou votre PC, avec accès à vos dossiers (Cowork), ou de Claude Code pour certains réglages avancés.

Sur claude.ai, ajouter ses propres skills demande une offre payante (Pro, Max, Ultra, Team ou Enterprise) et l’exécution de code activée dans les réglages.
