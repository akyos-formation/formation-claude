Notes pour le formateur

  • La démo utilise une fenêtre miniature de 10 000 tokens pour que le remplissage soit visible. Les vraies fenêtres de Claude font 200 000 tokens, voire jusqu'à 1 million selon le modèle et l'offre : le mécanisme est le même, seule l'échelle change.
  • Les seuils 50 / 75 / 90 % sont illustratifs. Claude Code résume automatiquement près de la limite (et à la demande avec /compact). Sur claude.ai, le comportement dépend de l'offre et évolue : vérifiez dans votre interface avant d'affirmer quoi que ce soit. D'autres outils suppriment simplement les messages les plus anciens (mode « oublie le début »).
  • À relier à la Leçon 2.6 : « Avant que ça sature, résumez », « Deux façons de repartir propre » (Compact ou Fresh + brief).
