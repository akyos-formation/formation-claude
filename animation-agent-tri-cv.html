Construire un agent de tri de CV

On part d'un modèle seul, puis on ajoute pièce par pièce ce qui en fait un agent fiable. À chaque étape, regardez ce que le système sait faire.

    Clavier : → ou espace pour avancer, ← pour reculer

    Notes pour le formateur

    • Les CV, notes et références (fiche RH-2026-14) sont fictifs. Les noms des outils (lire_pdf, écrire_tableur) sont illustratifs : dans Claude Code ou Cowork, ce sont des lectures de fichiers et des connecteurs.
    • Le tri de candidatures par IA est classé « à haut risque » par le règlement européen sur l'IA (AI Act, annexe III). Le calendrier d'application de ces obligations fait l'objet de discussions de report : vérifiez les dates en vigueur avant de les citer.
    • RGPD : informer les candidats du traitement, et ne pas laisser une décision produisant des effets importants reposer uniquement sur un traitement automatisé (article 22). Code du travail : critères discriminatoires interdits (article L1132-1).
    • Ne pas alimenter le RAG avec les recrutements passés sans précaution : l'agent reproduirait les biais des décisions antérieures.
