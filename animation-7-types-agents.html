Les 7 types d'agents Claude

Un agent est un Claude qui ne se contente plus de répondre : il agit, suit une méthode ou travaille avec d'autres agents. Faites circuler le travail dans chaque schéma pour voir ce qui les distingue.

À garder en tête

  • Plusieurs agents consomment plus de votre limite d'usage qu'un seul. Commencez petit, avec deux ou trois agents.
  • Gardez la validation humaine pour tout ce qui part chez un client, touche à l'argent ou ne peut pas être annulé.
  • Les types 3 à 7 se montent surtout dans Claude Code, avec la commande /agents, pas dans une simple conversation sur claude.ai.
  • Les noms des menus changent parfois. L'aide officielle de Claude fait foi.
