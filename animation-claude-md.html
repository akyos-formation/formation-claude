Créer le fichier avec Claude

      
À coller dans un projet qui n'a pas encore de CLAUDE.md. Dans Claude Code, la commande /init propose aussi un premier fichier en analysant le dossier.

      
Aide-moi à rédiger le CLAUDE.md de ce projet.

Pose-moi une question à la fois sur :
1. le but du projet et son public ;
2. le style attendu ;
3. les fichiers que tu dois lire ;
4. ce que tu ne dois jamais faire ;
5. comment vérifier ton travail.

Rédige ensuite un fichier de moins de 200 lignes.
Chaque consigne doit être concrète et vérifiable.
N'y mets ni mot de passe, ni clé, ni donnée client.

      
    

    

      
La boucle de vérification

      
À coller une fois dans CLAUDE.md ou dans les instructions de ton projet.

      
Pour chaque livrable (texte, tableau, synthèse) :
1. Produis une première version.
2. Vérifie-la par rapport à ma demande : erreurs, imprécisions, affirmations sans preuve.
3. Corrige, puis revérifie ta correction. Trois tours au maximum.
4. N'invente aucun fait. Si une information n'est pas dans ce que je t'ai fourni, signale-la.
5. Termine par un bilan de trois lignes : corrections faites, points à confirmer.
Affiche-moi seulement la version finale et le bilan.

      
    

    

      
Relire un CLAUDE.md existant

      
À utiliser quand Claude semble ignorer certaines règles.

      
Relis notre CLAUDE.md et signale :

- les consignes floues ou invérifiables ;
- les contradictions ;
- ce qui n'est vrai que pour ce mois-ci
  (à déplacer dans MEMORY.md) ;
- les procédures longues
  (à déplacer dans une Skill).

Propose les corrections sans modifier le fichier.
J'approuve chaque changement.
