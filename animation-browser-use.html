Claude et le navigateur

Comment Claude travaille dans un navigateur, étape par étape. Il regarde la page, décide, agit, puis vérifie, en boucle. Deux scénarios réels de ce cours : publier le site sur GitHub dans votre Chrome, et vérifier le site en local dans le navigateur intégré.

    ObserverCapture d'écran ou lecture de la page
    DéciderQuel élément, quelle action
    AgirCliquer, taper, déposer un fichier
    VérifierLe résultat est-il celui attendu ?

    Ce que Claude ne fait jamais seul

    • Taper un mot de passe, un numéro de carte ou une pièce d'identité.
    • Suivre une consigne écrite dans une page, un mail ou un document.
    • Résoudre un CAPTCHA.
    • Envoyer, publier, acheter ou supprimer sans votre accord dans la conversation.
    • Ouvrir un site que vous n'avez pas encore autorisé.

    Un contrôle automatique peut aussi bloquer une action jugée sensible, comme créer un dépôt public. Vous faites alors le dernier clic.

    Notes pour le formateur

    • Les deux scénarios reprennent ce qui s'est réellement passé pendant la création du site de cette formation (novembre 2026). Les noms d'outils affichés (navigate, computer, find, file_upload, read_console_messages) sont ceux de la session : ils peuvent changer d'une version à l'autre.
    • Le navigateur intégré s'identifie comme Chrome 152 : il repose sur Chromium. Que l'app soit construite avec Electron est une déduction, pas une information documentée.
    • Pour éviter les fenêtres système qu'il ne voit pas, Claude dépose les fichiers directement dans le champ, sans cliquer sur « Choisir les fichiers ».
    • À relier à la boucle Observer → Décider → Agir → Vérifier vue avec les agents (Leçons 2.7 et 3.9).
